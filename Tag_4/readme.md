# Tag 4: Schere, Stein, Papier ✂️🪨📄

Ein echter Klassiker für meine "100 Days of Code" Challenge! In diesem Projekt habe ich das bekannte Spiel "Schere, Stein, Papier" programmiert, bei dem man direkt gegen den Computer antritt.

## 📝 Was macht das Programm?
Das Programm bittet den Nutzer über die Konsole um eine Eingabe:
1. Schere
2. Stein
3. Papier

Anschließend wählt der Computer seine eigene "Hand" völlig zufällig aus. Das Programm vergleicht dann die beiden Entscheidungen nach den klassischen Regeln (Schere schlägt Papier, Stein schlägt Schere, Papier schlägt Stein) und gibt aus, ob man gewonnen hat, verloren hat oder ob es ein Unentschieden gab.
