# 🐍 100 Days of Code - Python Bootcamp

Willkommen in meinem Repository! 

Hier dokumentiere ich meine Reise durch den Kurs *"100 Days of Code: The Complete Python Pro Bootcamp"* von Angela Yu. Mein Ziel ist es, kontinuierlich am Ball zu bleiben und jeden Tag ein neues Projekt hochzuladen.

## 🎯 Mein Ziel
Ich lerne Python von Grund auf, um mir starke Programmier-Skills aufzubauen. Dieses Repository dient als mein persönliches Lerntagebuch und als Portfolio für meine zukünftige Karriere. 

## 📁 Wie dieses Repository funktioniert
* Jeder Tag hat einen eigenen Ordner (z.B. `Tag_1`, `Tag_2`).
* In jedem Ordner findest du meinen reinen, selbst geschriebenen Code (`main.py`).
* Der Code wird von mir regelmäßig und "up to date" gehalten.
