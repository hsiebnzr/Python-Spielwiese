# Tag 2: Trinkgeld-Rechner 💸

Zweiter Tag der "100 Days of Code" Challenge! Heute habe ich einen praktischen Trinkgeld-Rechner (Tip Calculator) programmiert, der eine Restaurantrechnung fair auf mehrere Personen aufteilt.

## 📝 Was macht das Programm?
Das Programm sammelt drei Eingaben vom Benutzer:
1. Die Gesamtkosten der Rechnung.
2. Das gewünschte Trinkgeld (z. B. 10, 20 oder 30 Prozent).
3. Die Anzahl der Personen, auf die die Rechnung aufgeteilt wird.

Anschließend berechnet es mathematisch den Gesamtbetrag inklusive Trinkgeld, teilt diesen durch die Personenanzahl und gibt den exakten Betrag pro Person formatiert (mit zwei Nachkommastellen) aus.
