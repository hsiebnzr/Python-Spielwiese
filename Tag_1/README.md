# Tag 1: Spitznamen-Generator 💡

Mein allererstes Python-Projekt! Zum Auftakt der "100 Days of Code" Challenge habe ich einen einfachen Generator programmiert, der aus Benutzereingaben einen lustigen Spitznamen erstellt.

## 📝 Was macht das Programm?
Das Programm stellt dem Nutzer über die Konsole zwei Fragen:
1. In welcher Stadt bist du aufgewachsen?
2. Wie hieß dein erstes Haustier?

Anschließend nimmt es diese beiden Antworten und fügt sie durch sogenannte Textverkettung (String Concatenation) zu einem neuen Ergebnis zusammen.
