# Tag 3: Schatzsuche 🏴‍☠️

Ein weiteres Projekt meiner "100 Days of Code" Challenge! Dieses Mal habe ich ein textbasiertes Abenteuerspiel programmiert, bei dem der Spieler clevere Entscheidungen treffen muss, um einen verborgenen Schatz zu finden.

## 📝 Was macht das Programm?
Das Programm führt den Nutzer durch eine kleine Geschichte und stellt ihn immer wieder vor verschiedene Wahlmöglichkeiten (z. B. links oder rechts gehen, auf ein Boot warten oder schwimmen):
* Trifft man eine **falsche Wahl**, gerät man in eine Falle (z. B. Haie oder ein Loch) und das Spiel endet sofort (Game Over).
* Trifft man die **richtige Wahl**, darf man weiterziehen.
* Wer es bis zum Ende schafft und alle richtigen Entscheidungen trifft, findet den Schatz und gewinnt das Spiel!
